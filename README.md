# 瑞昱承攬商線上安全衛生教育訓練 — 使用說明

網址：https://yayunku.github.io/rt-safety-training/

## 這個網站做什麼

入廠的承攬商人員在這裡完成線上訓練與測驗，全部答對後，系統自動發出一張【電子訓練合格證明】。之後本人可以用身分證字號＋姓名查回自己的證明，門口也可以掃證明上的 QR 確認是否有效。

首頁有三個入口：

| 入口 | 給誰 |
|---|---|
| 工程發包 | 一般作業、高風險作業等承攬商 |
| 勞務 | 保全、清潔、供膳、超商販售等承攬商 |
| 查詢合格證明 | 已經考過的人，用身分證字號＋姓名查詢 |

給廠商時，直接把網址傳給對方即可，對方用手機或電腦都能填。

---

## 承攬商會看到的流程

1. **基本資料**：先閱讀個資提供同意書並勾選「我同意」（沒勾之前其他欄位無法填寫），再填公司統編、公司名稱、姓名、身分證字號
2. **訓練教材**：觀看訓練影片、填觀看日期，並回答兩題「是／否」。選「否」就不能進到測驗
3. **訓練測驗**：20 題全部答對才算合格。答錯時頁面會標出錯的題號，改到全對為止

合格後畫面會出現電子訓練合格證明，可以下載成圖片或列印。

幾個檢查規則：

- 身分證字號接受本國身分證與居留證（新式、舊式），會檢查格式與檢查碼
- 公司統編會檢查 8 碼與檢查碼
- 觀看日期不能填未來的日期

## 電子訓練合格證明

- 證號格式：`RT-E-20261014-001`（E＝工程發包、S＝勞務，中間是發證日期，最後是當天流水號）
- **有效期限：發證日起 1 年**
- 證明上的身分證只顯示部分（`A12****789`）
- 工程發包類是藍色，勞務類是綠色
- 掃證明上的 QR 會打開查驗頁，即時顯示「有效／已過期／已作廢」。下載的圖片不會顯示綠色「有效」，因為存下來的圖片不知道自己過期了，要看即時狀態請掃 QR

### 查詢

查詢頁輸入身分證字號＋姓名，兩個都對才查得到。同一個人如果工程、勞務都考過，兩種各顯示最新的一張。

同一個身分證字號 15 分鐘內查錯 5 次會暫時鎖住，15 分鐘後自動解除。

## 資料放在哪裡

| 資料 | 位置 |
|---|---|
| 每一筆訓練回應 | 原本的兩份 Google 表單（回應照舊進表單，看資料的方式不變） |
| 發出的合格證明 | Apps Script 擁有者雲端硬碟裡的「承攬商電子訓練合格證明登記表」 |

登記表只存遮蔽後的身分證號，不存完整身分證字號。

**登記表不能刪除整份檔案**，後端靠它發證與查詢。要清資料時只刪「列」，不要只清內容。

## 日常維護

### 作廢一張證明

在登記表找到那一列，勾「作廢」欄，並在「作廢原因」寫原因。勾完立即生效，查詢和掃 QR 都會顯示「已作廢」。

### 修改題目或答案

直接改 Google 表單即可，網站會自動讀取最新的題目與答案。注意：

- 改完後最多 2 小時才會反映到網站。要立刻生效，到 Apps Script 編輯器開 `Server.gs`，執行 `clearFormCache`
- 每一題測驗都要在表單的「答案」設好正確選項與分數；沒設分數的題目不會被當成考題
- 「訓練教材」裡的「是／否」題**不要**設答案與分數
- 同意勾選題的標題要保留「個人資料提供同意書」這幾個字，後端靠它認出這一題；「統編」「身分證」「姓名」「公司名稱」這些欄位標題的關鍵字也要保留
- 不要開啟選項中的「其他」，也不要新增檔案上傳等其他題型，否則訓練頁會無法載入
- 表單要維持「不收集電子郵件」、「不限制只能回覆 1 次」，以及「接受回覆」開啟

### 修改後端程式

```bash
cd apps-script && clasp push
```

然後到 Apps Script 編輯器：「部署」→「管理部署作業」→ 鉛筆圖示 → 版本選「新版本」→「部署」。

**不要按「新增部署作業」**，那會產生新網址，網站就連不到後端了。

### 修改網頁

改完 push 到 `main`，GitHub Pages 約 1–5 分鐘後更新。

## 第一次部署（換帳號或重建時才需要）

1. 用 Apps Script 擁有者帳號開啟 Google Apps Script API（https://script.google.com/home/usersettings）
2. 安裝 clasp 並登入：`npm install -g --prefix ~/.local @google/clasp`，再 `clasp login`
3. 在 script.google.com 建新專案，把指令碼 ID 填進 `apps-script/.clasp.json`（從 `.clasp.json.example` 複製，這個檔案不會進版控）
4. `cd apps-script && clasp push`
5. 在編輯器執行 `setup`：建立登記表、金鑰與每小時預熱排程，可重複執行
6. 「專案設定」→「指令碼屬性」新增 `FORM_ID_E`、`FORM_ID_S`（兩份表單編輯網址中 `/d/` 後面那串）。這個帳號必須是兩份表單的編輯者
7. 「部署」→「新增部署作業」→ 網頁應用程式，執行身分「我」，存取權「所有人」
8. 把部署網址（結尾 `/exec`）填進 `config.js`，push 到 `main`

`HMAC_SECRET` 與 `REGISTRY_SHEET_ID` 由 `setup` 自動產生，**不要修改**。換掉 `HMAC_SECRET` 會讓所有已發出的證明都查不到、QR 也失效。
